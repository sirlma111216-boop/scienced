# 2026-11-22 강의 개편 및 교육과정 자료실 검토

## 강의 구성

과학교육론은 11강으로 마친다. 1~7강은 기존 흐름을 유지하고, 8강 비유·모형, 9강 논증과 협동학습, 10강 과학 관련 사회적 쟁점, 11강 평가로 구성했다. 옛 11강의 협동학습 핵심을 9강에 통합하고 포용적 지원을 11강 평가와 연결했다. 옛 12강의 평가 내용을 11강으로 개편했다. 과거 12강 파일은 기존 기록 참조를 위해 남기되 현재 색인에서는 제외했다. 저장된 학생 응답은 변경하지 않았다.

## 내용과 표현

- 교육론 8~11강과 교수법 17·18강의 도입, 모든 개념 카드, 확인 문항, 활동, 공유·모둠 안내, 정리 문항을 검토했다.
- 개념은 핵심 문장, 쉬운 설명, 실제 교실 사례, 판단 기준 순으로 제시한다. 다단계 설명은 번호와 줄바꿈으로 구분한다.
- 활동 자료는 학생 반응, 교사가 가진 자료, 후속 수업 상황을 명시한다. 작성 칸에는 무엇을 써야 하는지 안내한다.
- 교수법 17강 조석 활동은 수업용 가상 관측값을 제공한다. 교수법 18강은 관찰하지 않은 수업 장면을 지어내지 않고 제시된 기록을 근거로 수정하게 한다.
- 교육론의 교실 사례와 활동은 호흡, 효소·소화, 광합성·증산, 생태계 등 생명과학 중심이다.
- 교수법 17강의 주요 사례: 물리(시뮬레이션·직렬 회로), 화학(반응식·검증), 생명(항생제 설명), 지구과학(계절·조석). 교수법 18강: 물리(열·피드백), 화학(용해·증거 해석), 생명(광합성·PCK), 지구과학(달의 위상·수업 수정). 두 강 모두 네 영역을 포함한다.
- 게임: 교육론 8강 반응속도 하위, 9강 가위바위보 먼저 패한 사람, 10강 마지막까지 탈출하지 못한 사람, 11강 폭탄을 들고 끝난 사람. 교수법 17강 반응속도 하위, 18강 폭탄을 들고 끝난 사람. 실제 선정 로직을 사용한 자동 모의 실행으로 전체 참여·일부 참여·무응답 조건에서 종료와 발표자 두 명 선정을 확인했다.
- 기존 강조 표시 때문에 끊어진 교수법 3·7강의 용어 팝오버 연결 문구도 실제 강조 구간에 맞게 수정했다.

## 교육과정과 메뉴

홈 및 공통 하단의 포트폴리오·개념지도 메뉴를 제거했다. 기존 데이터는 삭제하지 않았다.

교육과정 독립 메뉴의 대표 예시 검색기를 제공받은 교육부 고시 제2022-33호 [별책 9] 과학과 교육과정 전체 292쪽으로 교체했다. 18개 과목 묶음의 시작 쪽은 PDF 목차와 본문에서 대조했다. 원본 PDF, 페이지별 검색 텍스트, 원문 페이지 이미지를 제공한다. 본문 쪽수와 PDF 쪽수를 함께 표시한다. 텍스트는 추출본이므로 표의 배치와 기호는 원문 이미지/PDF로 확인한다. 키워드·성취기준 코드 검색은 띄어쓰기를 무시한다.

원문 출처: 사용자 제공 `[별책9] 과학과 교육과정 (3).pdf`. 파일은 수정하지 않고 복사했다. 최신 고시 개정본이라는 별도 주장은 하지 않으며 제공된 2022-33호를 명시한다.
