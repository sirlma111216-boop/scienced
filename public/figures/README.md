# 교재 그림

앱이 그림을 그리지 않는다. 강의자가 만들어 여기에 넣는다.

만드는 데 필요한 것(생성 프롬프트·반드시 보여야 할 것·보이면 안 되는 것)은
**강사 계정으로 그 차시를 열면 자료 카드 아래 「그림 만들기」**에 그대로 나온다.
소스에서는 `src/content/lessons/*.ts` 의 `imageSpec` 이다.

파일 이름은 `imageSpec.src` 와 정확히 같아야 한다. 지금 기다리는 파일:

| 파일 | 차시 | 무엇 |
|---|---|---|
| `02-footprints.png` | 2강 도입 | 발자국 두 줄 |

파일이 없으면 화면이 비지 않는다 — 대체 설명과 표 대안이 대신 나온다.
